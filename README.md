# 申請書自動入力アプリ（companyformautomation）

会社設立に必要な登記申請書・定款・印鑑届出書をフォーム入力から自動生成し、Google ドライブへアップロード・スプレッドシートに記録するアプリケーションです。

## セットアップ

**セットアップ手順は [docs/SETUP.md](docs/SETUP.md) にまとめています。**

- ローカル開発（バックエンド / フロントエンド）
- 環境変数・テンプレート配置
- Google Cloud（Drive / Sheets）設定
- Render へのデプロイ
- メール添付（オプション）は [docs/email-attachment-setup.md](docs/email-attachment-setup.md) を参照
